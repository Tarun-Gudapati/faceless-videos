Tool stack (cheap and enough)

Pick one tool per row. Free tiers cover the first 50 videos.

Script

Notion or Google Docs. One idea → hook → 3 beats → CTA. Keep every short under 110 words.

Voice

ElevenLabs or CapCut TTS. Warm, mid male/female Indian-friendly voice. Speed 1.05–1.1.

Visuals

Screen recordings (OBS / Loom), CapCut stock, Pexels campus/coding clips, Canva kinetic text.

Edit + captions

CapCut auto captions → fix names (LLM, RAG, LoRA). Burn-in large captions for mute scrollers.

Music

CapCut copyright-safe beds at −18 to −22 dB under voice. No lyric tracks.

Thumbnail / cover

Bold Syne-style title, one code snippet, lime accent. Same template every post = brand memory.

Production pipeline

Same loop every time. Do not invent a new format mid-week.

  1. 1
    Pick one buyer pain Placements, FOMO about AI jobs, “ML maths panic”, “YouTube never ends”, “no projects on resume”.
  2. 2
    Write the hook in one line First 1.5 seconds must stop the thumb. Pattern: bold claim + specific skill (“Your PDF chatbot is a RAG app”).
  3. 3
    Generate voice, then visuals Voice first locks timing. Cut screen demos and B-roll to the audio, not the other way around.
  4. 4
    Captions + end card Big captions. Last 3 seconds: “Module 1 free” + link in bio / BeyondPlaced URL.
  5. 5
    Post daily, recycle winners Turn a winning Reel into a 3–5 min YouTube Shorts compilation or a carousel script.

Publish rules

Distribution beats polish after video #10.

IG / YT

Cadence

CTA

One link only

KPI

Measure the sale

Track saves + profile visits + free signups. Ignore vanity likes until signups move.
